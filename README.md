# PC Monitor

A lightweight Python-based system monitor with a live terminal dashboard.

## Features
- CPU and RAM monitoring with history graphs
- Disk capacity and usage information
- Network interfaces and IP addresses
- Live dashboard powered by Rich

## Installation
```powershell
python -m pip install -r requirements.txt
```

## Usage
```powershell
python main.py
```

Press Q to exit.

## Technologies
- Python
- psutil
- Rich
- keyboard
